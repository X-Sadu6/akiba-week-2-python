## Completed Tasks

### Task 01 — Even or Odd

Determines whether a user-provided integer is even or odd, including negative numbers and zero.

**Concepts:** Modulo operator, user input, and conditional statements.

### Task 02 — Largest of Three

Compares three numbers to determine the largest, handling equal values.

**Concepts:** Comparison operators and conditional logic.

### Task 03 — Prime Number Checker

Checks whether an integer greater than one is prime by testing possible divisors.

**Concepts:** Loops, conditions, modulo, and optimization.

### Task 04 — Palindrome Checker

Checks whether a word reads the same forward and backward, ignoring letter case.

**Concepts:** Strings, string methods, and comparisons.

### Task 05 — Sum of Digits

Calculates the sum of the digits of a number using a loop.

**Concepts:** Arithmetic operations and iterative processing.

### Task 06 — FizzBuzz

Processes a range of numbers, printing `Fizz` for multiples of 3, `Buzz` for multiples of 5, and `FizzBuzz` for multiples of both.

**Concepts:** Loops, modulo, and conditional ordering.

### Task 07 — Number Guessing Game

Allows a user to guess a secret number, with an optional attempt counter and maximum-attempt limit.

**Concepts:** Loops, conditions, counters, and user interaction.

### Task 08 — Count Numbers

Counts even and odd numbers from 1 to a given positive integer and calculates their total sum.

**Concepts:** Iteration, counters, accumulators, and computational thinking.

### Task 09 — ATM PIN System

Verifies a PIN using a limited number of attempts and reports the remaining attempts.

**Concepts:** While loops, conditions, counters, and input validation.

### Task 10 — Number Analyzer

Analyzes ten user-provided numbers to calculate the largest, smallest, sum, average, and counts of even and odd numbers.

**Concepts:** Loops, accumulators, comparisons, counters, and basic statistics.

## Mini Project — Simple Bank Account System

The mini-project is a menu-driven banking application that simulates basic account operations.

### Features

- **Check Balance:** Displays the current account balance.
- **Deposit Money:** Adds a valid positive amount to the balance.
- **Withdraw Money:** Withdraws a valid amount when sufficient funds are available.
- **PIN Verification:** Restricts access after repeated incorrect PIN attempts.
- **Transaction Counter:** Optionally tracks successful deposits and withdrawals.
- **Input Validation:** Handles invalid menu choices and invalid transaction amounts.
- **Exit:** Ends the program when the user chooses to exit.

**Starting balance:** 1,000 Birr

**File:** `mini_project_bank.py`

## Computational Thinking Approach

The assignments encourage a structured approach to solving programming problems:

1. **Understand:** Identify the problem and its requirements.
2. **Break Down:** Divide the problem into smaller tasks.
3. **Identify Patterns:** Find repeated operations and useful relationships.
4. **Design:** Choose suitable conditions, loops, and variables.
5. **Implement:** Translate the logic into Python code.
6. **Test:** Check expected results, unusual inputs, and edge cases.
7. **Improve:** Make the solution clearer, more reliable, and more efficient.

## Testing and Edge Cases

The programs should be tested with appropriate cases, including:

- Zero and negative numbers where applicable.
- Equal numbers in comparison tasks.
- Prime-number boundary cases such as 0, 1, and 2.
- Uppercase and lowercase letters in palindrome checks.
- Invalid menu selections and invalid transaction amounts.
- Incorrect PINs and maximum-attempt limits.
- Numbers that produce different even and odd counts.
